# Skipper

**1. To start work clone this repo and move to the project directory**
```bash
git clone https://github.com/NeZeRky/Skipper

cd Skipper
```

**2. Install necessary dependences and run script**
```bash
npm install

mode remanga.js
```
**3. Set your auth token in the remanga.js on place "YOUR_BEARER_TOKEN"**
